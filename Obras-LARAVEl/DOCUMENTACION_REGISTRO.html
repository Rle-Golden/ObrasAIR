4. Flujo del Registro

5. Notas Importantes

ℹ️ Información General

El sistema de registro ahora está completamente funcional y listo para ser utilizado. Los usuarios pueden crear nuevas cuentas y luego proceder a seleccionar su rol (Administrador, Representante de empresa, o Aspirante).

⚠️ Nota sobre las Contraseñas

La base de datos original especifica un máximo de 10 caracteres para las contraseñas. Por esta razón, se mantiene ese límite en la validación. Para futuras mejoras, se recomienda incrementar este límite en la BD y utilizar hash de contraseñas (bcrypt) para mejor seguridad.

🔒 Seguridad

El formulario incluye CSRF token (aunque no es requerido en este caso porque usamos JavaScript puro). Se recomienda siempre validar en el servidor, nunca solo en cliente. El RegisterController realiza validación completa del lado del servidor.

✓ Próximos Pasos

Después del registro exitoso, el usuario es redirigido a /roles.html. Allí deberá seleccionar su rol (Aspirante, Empresa, etc.). Este flujo está listo para ser integrado con la lógica de selección de roles y el login posterior.

Validaciones Implementadas:

  • Tipo de documento: Solo acepta valores válidos (CC, CE, PA, PPT, PEP)
  • Número de documento: Debe ser numérico y único en la BD
  • Nombres y apellidos: Máximo 20 caracteres, no puede estar vacío (primero de cada uno)
  • Email: Debe ser un email válido y único en la BD
  • Celular: Debe ser numérico
  • Contraseña: Mínimo 6 caracteres, máximo 10 (por limitación de BD)
  • Confirmación: Debe coincidir exactamente con la contraseña

Prueba del Sistema:

Para probar el registro:

  1. Abre http://127.0.0.1:8000/registro.html
  2. Completa todos los campos (ejemplo: CC, 123456789, Juan, Pérez, juan@email.com, etc.)
  3. Asegúrate de que las contraseñas coincidan
  4. Haz clic en "Registrarme"
  5. Deberías ver un mensaje de éxito y ser redirigido a /roles.html
